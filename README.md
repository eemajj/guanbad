# ระบบจัดการก๊วนแบดมินตัน

เว็บแอปสำหรับหัวก๊วนและสมาชิก: เปิดรอบตี ลงชื่อ จัดคู่อัตโนมัติ คิดค่าคอร์ท/ค่าลูก และเก็บเงินผ่าน QR พร้อมเพย์
สมาชิกเข้าระบบด้วย **ชื่อ + PIN** ไม่ต้องสมัคร ไม่ต้องมีอีเมลหรือ LINE

## ความสามารถ

| ส่วน | หัวก๊วน | สมาชิก |
|---|---|---|
| **รอบตี** | เปิด/แก้ไขรอบ (สนาม วันเวลา คอร์ท ค่าคอร์ท ค่าลูก จำนวนรับสูงสุด) · เริ่มตี · จบรอบและออกบิล | ดูรอบ · ลงชื่อ / ถอนชื่อ |
| **ผู้เล่น** | เพิ่มจากทะเบียน (เลือกหลายคน) หรือเพิ่มคนใหม่ · พัก / กลับมาเล่น / กลับบ้าน · ลบ | ขอพัก / กลับมาเล่น ของตัวเอง |
| **คอร์ท** | จัดคู่ลงคอร์ทว่าง · จบเกม (ทีมที่ชนะ + จำนวนลูก) แล้วจัดคู่ถัดไปให้ทันที · เปลี่ยนตัว · ยกเลิกเกม | ดูคอร์ท คิว และผลการแข่ง (อัปเดตเองทุก 8 วินาที) |
| **เงิน** | ยืนยันรับเงิน · ยกเว้นบิล · บันทึกรายจ่าย · สรุปรายเดือน · ยอดค้างทั้งหมด | จ่ายผ่าน QR พร้อมเพย์ที่ใส่ยอดไว้แล้ว · แจ้งโอน |
| **สมาชิก** | ทะเบียนสมาชิก สถิติ ยอดค้าง · ตั้ง/รีเซ็ต PIN · ตั้งหัวก๊วนร่วม | โปรไฟล์ ประวัติ บิลของตัวเอง · เปลี่ยน PIN |
| **สถิติ** | ใส่ผล/แต้มตอนจบเกม หรือเติมย้อนหลัง · เห็นรอบที่ยังไม่ได้บันทึกผล | อันดับ ชนะ–แพ้ แต้มได้–เสีย คู่ที่เข้าขา (เดือนนี้ / 3 เดือน / ทั้งหมด) |

### กติกาที่ระบบใช้

**การจัดคู่** (`src/domain/matchmaking.ts`)
1. คนที่รอนานที่สุดได้ลงก่อน เวลารอนับจากตอนมาถึง จบเกมล่าสุด หรือกลับจากพัก
2. คนหัวคิวได้ลงแน่นอน อีก 3 คนเลือกจาก 6 คนถัดไป
3. ระบบเลือกชุด 4 คนและวิธีแบ่งทีมที่ทำให้ผลรวมระดับมือสองฝั่งใกล้กันที่สุด เลี่ยงจับระดับที่ห่างกันมากลงเกมเดียวกัน และเลี่ยงคู่ที่เคยจับคู่หรือเจอกันแล้ว
4. ระดับมือใช้เกณฑ์ของก๊วน 7 ระดับ: BG, N-, N, NS, S, P-, P (`src/domain/levels.ts`)

**ผลการแข่งและสถิติ** (`src/domain/results.ts`)
- ผลของแต่ละเกมไม่บังคับ เพราะในสนามมักลืมกด แบ่งเป็น 3 แบบ:

  | ที่บันทึก | นับเป็นเกมที่เล่น | นับชนะ/แพ้ | นับแต้ม |
  |---|---|---|---|
  | ไม่ได้บันทึก | ✓ | – | – |
  | ทีมที่ชนะ | ✓ | ✓ | – |
  | แต้ม | ✓ | ✓ (คิดผู้ชนะจากแต้ม) | ✓ |

- อัตราชนะ = ชนะ ÷ (ชนะ + แพ้) เกมที่ไม่มีผลจึงไม่ถูกนับเป็นแพ้
- แต้ม +/− เฉลี่ยจากเกมที่มีแต้มเท่านั้น
- ระบบตรวจข้อมูลก่อนบันทึก: ต้องใส่แต้มครบทั้งสองฝั่ง แต้มเท่ากันไม่ได้ ต้องเป็น 0–50 และต้องไม่ขัดกับทีมที่เลือกว่าชนะ
- เติมหรือแก้ผลย้อนหลังได้ทุกเกม ส่วนจำนวนลูกแก้ได้เฉพาะก่อนออกบิล
- การติดอันดับต้องมีเกมที่รู้ผลขั้นต่ำ: เดือนนี้ 4 เกม, 3 เดือน 8 เกม, ทั้งหมด 10 เกม กันไม่ให้คนที่เล่นเกมเดียวแล้วชนะขึ้นอันดับ 1
- หน้าสถิติแสดงเปอร์เซ็นต์ที่บันทึกผล และลิงก์ไปรอบที่ยังไม่ได้บันทึก

**ค่าใช้จ่าย** (`src/domain/fees.ts`)
- ค่าคอร์ท = จำนวนคอร์ท × ชั่วโมง × ค่าคอร์ทต่อชั่วโมง
  - แบบ "หารเท่ากัน": หารทุกคนที่มาร่วมรอบ รวมคนที่กลับก่อน
  - แบบ "คนละเท่ากัน": เก็บตามจำนวนที่ตั้งไว้
- ค่าลูก = จำนวนลูกที่ใช้ในแต่ละเกม × ราคาลูก ÷ 4 คนในเกมนั้น
- ยอดของแต่ละคนปัดขึ้นเป็นบาทเต็ม เงินทั้งหมดเก็บเป็นสตางค์ในฐานข้อมูล ทำให้ไม่มีปัญหาทศนิยม
- เมื่อกด "จบรอบ" ระบบจะ:
  - ยกเลิกเกมที่ยังค้างอยู่บนคอร์ท (ไม่นับ ไม่คิดค่าลูก)
  - ออกบิลให้ทุกคน
  - บันทึกรายจ่ายค่าคอร์ทและค่าลูกเข้าบัญชีอัตโนมัติ

**สิทธิ์**
- เข้าระบบ: เลือกชื่อตัวเอง แล้วใส่ PIN สมาชิก 4–8 หลัก หัวก๊วน 6–8 หลัก ห้ามเลขซ้ำหรือเรียงกัน (เช่น 1111, 1234) ระบบจำไว้ 60 วัน
- หัวก๊วนตั้ง PIN ให้สมาชิกในหน้าของสมาชิกแต่ละคน (ครั้งแรก และตอนลืม) สมาชิกเปลี่ยนเองได้ที่หน้า "ของฉัน"
- กันสุ่มเดา: ใส่ผิด 5 ครั้งติด รอ 15 นาที ผิด 10 ครั้งติด ล็อกจนหัวก๊วนตั้ง PIN ใหม่ (ระบบนับครั้งก่อนตรวจ ยิงพร้อมกันหลายครั้งก็ไม่หลุด) และจากเครือข่ายเดียวกันลองผิดได้ไม่เกิน 8 ชื่อต่อชั่วโมง PIN เก็บเป็น hash (scrypt) ไม่มีใครเห็น PIN จริง
- การจำกัดต่อเครือข่ายอ่าน IP จาก `x-real-ip` / `x-forwarded-for` ซึ่ง Vercel ตั้งให้เอง ถ้าใช้โฮสต์อื่นให้ตั้ง proxy ให้เขียนทับ header นี้
- ตั้ง PIN ใหม่ หรือย้ายไป "ไม่ได้มาแล้ว" ทุกเครื่องที่ล็อกอินค้างไว้จะหลุดทันที ถอดสิทธิ์หัวก๊วนก็มีผลในคลิกถัดไป
- หัวก๊วนคนแรกตั้งที่หน้าเข้าสู่ระบบตอนยังไม่มีหัวก๊วน บนเว็บจริงต้องใส่ `SETUP_CODE` (ตั้งใน env) กันคนอื่นแย่งตั้งก่อน
- หัวก๊วนลืม PIN หรือถูกล็อก: กด "หัวก๊วนลืม PIN" ที่หน้าเข้าสู่ระบบ ใส่ `SETUP_CODE` แล้วตั้ง PIN ใหม่ได้เอง ใช้ได้แม้หัวก๊วนทุกคนถูกล็อก
- หัวก๊วนตั้ง/ถอดหัวก๊วนร่วมได้จากหน้าสมาชิก ระบบกันไม่ให้เหลือหัวก๊วนที่เข้าระบบได้ 0 คน
- ทุก action ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ สมาชิกแก้ได้เฉพาะข้อมูลของตัวเอง
- หน้าจ่ายเงิน `/pay/<id>` เปิดได้โดยไม่ต้องล็อกอิน ลิงก์เดาไม่ได้ ส่งให้คนที่ไม่มี PIN ทาง LINE ได้
- การจัดคู่และการเปลี่ยนสถานะถูกล็อกต่อรอบ (PostgreSQL advisory lock) ถ้าหัวก๊วนสองคนกดพร้อมกัน จะไม่มีใครถูกจัดลงสองคอร์ทพร้อมกัน

## เทคโนโลยี

- Next.js 15 (App Router, Server Actions) + React 19 + TypeScript
- PostgreSQL + Prisma
- Auth.js (NextAuth v5) เข้าระบบด้วยชื่อ + PIN
- Tailwind CSS รองรับโหมดมืดตามเครื่อง
- Vitest สำหรับทดสอบ logic การจัดคู่ ค่าใช้จ่าย และ QR พร้อมเพย์

```
src/
  domain/        logic ล้วน ไม่แตะฐานข้อมูล (จัดคู่, คิดเงิน, พร้อมเพย์, ระดับมือ) + เทสต์
  server/        อ่านข้อมูล (queries, session-state) และ server actions ที่ตรวจสิทธิ์
  components/    UI ที่ใช้ซ้ำ (ui/ = design system พื้นฐาน, session/ = หน้ารอบตี)
  app/           หน้าเว็บ: (app)/ = หลังล็อกอิน, pay/ login/ = หน้าสาธารณะ
prisma/          schema, migrations, ข้อมูลตัวอย่าง
```

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป และ Docker (หรือ PostgreSQL ของตัวเอง)

```bash
docker compose up -d
```

```bash
cp .env.example .env
```

แก้ไฟล์ `.env` ดังนี้:
- ใส่ `AUTH_SECRET` (สร้างด้วย `openssl rand -base64 32`)

```bash
npm install
```

```bash
npx prisma migrate dev
```

ใส่ข้อมูลตัวอย่าง (ไม่บังคับ): สมาชิก 12 คน รอบที่จบแล้ว 1 รอบ และรอบที่เปิดรับชื่อ 1 รอบ หัวก๊วนคือ "ต้น" PIN `135790` สมาชิกคนอื่น PIN `2580`

```bash
npm run db:seed
```

```bash
npm run dev
```

เปิด http://localhost:3000 แล้วเลือกชื่อ + ใส่ PIN ถ้าไม่ได้ใส่ข้อมูลตัวอย่าง หน้าแรกจะให้ตั้งหัวก๊วนคนแรก (ในเครื่องไม่ต้องใช้ `SETUP_CODE`) เปิดอีกเบราว์เซอร์ (หรือหน้าต่างไม่ระบุตัวตน) แล้วเข้าด้วยชื่อสมาชิก เพื่อลองในมุมสมาชิก

ตรวจโค้ด:

```bash
npm test
```

```bash
npm run lint
```

## ขึ้นเว็บจริง (Vercel + Neon/Supabase)

1. สร้างฐานข้อมูล PostgreSQL ฟรีที่ [Neon](https://neon.tech) หรือ [Supabase](https://supabase.com) แล้วคัดลอก connection string
2. push โค้ดขึ้น GitHub แล้ว Import โปรเจกต์ใน [Vercel](https://vercel.com)
3. ตั้ง Environment Variables ใน Vercel:
   - ตั้งค่า: `DATABASE_URL`, `AUTH_SECRET`, `AUTH_URL` (= URL ของเว็บ), `SETUP_CODE` (รหัสยาว 12 ตัวขึ้นไปที่รู้คนเดียว เช่น `openssl rand -hex 8` เก็บไว้ใช้ตอนหัวก๊วนลืม PIN ด้วย)
4. ตั้ง Build Command เป็น `prisma migrate deploy && npm run build` เพื่อให้ตารางในฐานข้อมูลถูกสร้างหรืออัปเดตทุกครั้งที่ deploy
5. เปิดเว็บ ใส่ `SETUP_CODE` ชื่อเล่น และ PIN 6 หลักของหัวก๊วน → เมนู **ตั้งค่า** → ใส่ชื่อก๊วนและพร้อมเพย์
6. เพิ่มสมาชิก แล้วตั้ง PIN ให้แต่ละคน ส่ง PIN ทางแชทส่วนตัว (ไม่ใช่ในกลุ่ม)

ใช้กับ Railway, Render หรือเซิร์ฟเวอร์ของตัวเองได้เหมือนกัน รัน `npm run build` แล้ว `npm start` ทำงานบน Node.js ปกติ

## การใช้งานในแต่ละรอบ

1. **หัวก๊วน** เปิดรอบใหม่ แล้วส่งลิงก์รอบในกลุ่ม LINE
2. **สมาชิก** กดลงชื่อ หัวก๊วนเพิ่มคนที่ยังไม่มี PIN ให้ได้
3. ถึงสนาม หัวก๊วนกด **เริ่มตี** ระบบจัดคู่ลงทุกคอร์ท
4. จบแต่ละเกม หัวก๊วนกด **จบเกม** เลือกทีมที่ชนะและจำนวนลูก ระบบจัดเกมใหม่ลงคอร์ทนั้นทันที
5. ใครเหนื่อยกด **ขอพัก** เองได้ ถ้ากำลังเล่นอยู่จะได้พักหลังจบเกม
6. เลิกตี หัวก๊วนกด **จบรอบ & ออกบิล**
7. สมาชิกเปิดบิล สแกน QR จ่าย แล้วกด **แจ้งโอน** หัวก๊วนเห็นรายการที่หน้าแรกแล้วกด **ยืนยันรับเงิน**
