# ระบบจัดการก๊วนแบดมินตัน

เว็บแอปสำหรับหัวก๊วนและสมาชิก: เปิดรอบตี ลงชื่อ จัดคู่อัตโนมัติ คิดค่าคอร์ท/ค่าลูก และเก็บเงินผ่าน QR พร้อมเพย์
สมาชิกล็อกอินด้วย **LINE** ไม่ต้องสมัครอะไรเพิ่ม

## ความสามารถ

| ส่วน | หัวก๊วน | สมาชิก |
|---|---|---|
| **รอบตี** | เปิด/แก้ไขรอบ (สนาม วันเวลา คอร์ท ค่าคอร์ท ค่าลูก จำนวนรับสูงสุด) · เริ่มตี · จบรอบและออกบิล | ดูรอบ · ลงชื่อ / ถอนชื่อ |
| **ผู้เล่น** | เพิ่มจากทะเบียน (เลือกหลายคน) หรือเพิ่มคนใหม่ · พัก / กลับมาเล่น / กลับบ้าน · ลบ | ขอพัก / กลับมาเล่น ของตัวเอง |
| **คอร์ท** | จัดคู่ลงคอร์ทว่าง · จบเกม (ทีมที่ชนะ + จำนวนลูก) แล้วจัดคู่ถัดไปให้ทันที · เปลี่ยนตัว · ยกเลิกเกม | ดูคอร์ท คิว และผลการแข่ง (อัปเดตเองทุก 8 วินาที) |
| **เงิน** | ยืนยันรับเงิน · ยกเว้นบิล · บันทึกรายจ่าย · สรุปรายเดือน · ยอดค้างทั้งหมด | จ่ายผ่าน QR พร้อมเพย์ที่ใส่ยอดไว้แล้ว · แจ้งโอน |
| **สมาชิก** | ทะเบียนสมาชิก สถิติ ยอดค้าง · ลิงก์ผูกบัญชี LINE · ตั้งหัวก๊วนร่วม | โปรไฟล์ ประวัติ บิลของตัวเอง |

### กติกาที่ระบบใช้

**การจัดคู่** (`src/domain/matchmaking.ts`)
1. คนที่รอนานที่สุดได้ลงก่อน เวลารอนับจากตอนมาถึง จบเกมล่าสุด หรือกลับจากพัก
2. คนหัวคิวได้ลงแน่นอน อีก 3 คนเลือกจาก 6 คนถัดไป
3. ระบบเลือกชุด 4 คนและวิธีแบ่งทีมที่ทำให้ผลรวมระดับมือสองฝั่งใกล้กันที่สุด เลี่ยงจับระดับที่ห่างกันมากลงเกมเดียวกัน และเลี่ยงคู่ที่เคยจับคู่หรือเจอกันแล้ว
4. ระดับมือใช้เกณฑ์ของก๊วน 7 ระดับ: BG, N-, N, NS, S, P-, P (`src/domain/levels.ts`)

**ค่าใช้จ่าย** (`src/domain/fees.ts`)
- ค่าคอร์ท = จำนวนคอร์ท × ชั่วโมง × ค่าคอร์ทต่อชั่วโมง
  - แบบ "หารเท่ากัน": หารทุกคนที่มาร่วมรอบ รวมคนที่กลับก่อน
  - แบบ "คนละเท่ากัน": เก็บตามจำนวนที่ตั้งไว้
- ค่าลูก = จำนวนลูกที่ใช้ในแต่ละเกม × ราคาลูก ÷ 4 คนในเกมนั้น
- ยอดของแต่ละคนปัดขึ้นเป็นบาทเต็ม เงินทั้งหมดเก็บเป็นสตางค์ในฐานข้อมูล ทำให้ไม่มีปัญหาทศนิยม
- เมื่อกด "จบรอบ" ระบบจะ:
  - ยกเลิกเกมที่ยังค้างอยู่บนคอร์ท (ไม่นับ ไม่คิดค่าลูก)
  - ออกบิลให้ทุกคน
  - บันทึกรายจ่ายค่าคอร์ทและค่าลูกเข้าบัญชีอัตโนมัติ

**สิทธิ์**
- คนแรกที่ล็อกอินจะเป็นหัวก๊วนโดยอัตโนมัติ หรือกำหนดหัวก๊วนเองด้วย `ADMIN_LINE_IDS`
- ทุก action ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ สมาชิกแก้ได้เฉพาะข้อมูลของตัวเอง
- หน้าจ่ายเงิน `/pay/<id>` เปิดได้โดยไม่ต้องล็อกอิน ลิงก์เดาไม่ได้ ส่งให้คนที่ไม่มีบัญชีทาง LINE ได้
- การจัดคู่และการเปลี่ยนสถานะถูกล็อกต่อรอบ (PostgreSQL advisory lock) ถ้าหัวก๊วนสองคนกดพร้อมกัน จะไม่มีใครถูกจัดลงสองคอร์ทพร้อมกัน

## เทคโนโลยี

- Next.js 15 (App Router, Server Actions) + React 19 + TypeScript
- PostgreSQL + Prisma
- Auth.js (NextAuth v5) + LINE Login
- Tailwind CSS รองรับโหมดมืดตามเครื่อง
- Vitest สำหรับทดสอบ logic การจัดคู่ ค่าใช้จ่าย และ QR พร้อมเพย์

```
src/
  domain/        logic ล้วน ไม่แตะฐานข้อมูล (จัดคู่, คิดเงิน, พร้อมเพย์, ระดับมือ) + เทสต์
  server/        อ่านข้อมูล (queries, session-state) และ server actions ที่ตรวจสิทธิ์
  components/    UI ที่ใช้ซ้ำ (ui/ = design system พื้นฐาน, session/ = หน้ารอบตี)
  app/           หน้าเว็บ: (app)/ = หลังล็อกอิน, pay/ claim/ login/ welcome/ = หน้าสาธารณะ
prisma/          schema, migrations, ข้อมูลตัวอย่าง
```

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป และ Docker (หรือ PostgreSQL ของตัวเอง)

```bash
docker compose up -d
```

```bash
cp .env.example .env
```

แก้ไฟล์ `.env` ดังนี้:
- ใส่ `AUTH_SECRET` (สร้างด้วย `openssl rand -base64 32`)
- ถ้าจะลองโดยยังไม่ตั้ง LINE ให้ตั้ง `ALLOW_DEV_LOGIN="true"`

```bash
npm install
```

```bash
npx prisma migrate dev
```

ใส่ข้อมูลตัวอย่าง (ไม่บังคับ): สมาชิก 12 คน รอบที่จบแล้ว 1 รอบ และรอบที่เปิดรับชื่อ 1 รอบ

```bash
npm run db:seed
```

```bash
npm run dev
```

เปิด http://localhost:3000 แล้วล็อกอินด้วยชื่ออะไรก็ได้ คนแรกจะเป็นหัวก๊วน เปิดอีกเบราว์เซอร์ (หรือหน้าต่างไม่ระบุตัวตน) แล้วล็อกอินด้วยชื่ออื่น เพื่อลองในมุมสมาชิก

ตรวจโค้ด:

```bash
npm test
```

```bash
npm run lint
```

## ตั้งค่า LINE Login

1. ไปที่ https://developers.line.biz/console/ → สร้าง Provider → สร้าง channel แบบ **LINE Login**
2. ในแท็บ **LINE Login** ใส่ Callback URL:
   - ตอนพัฒนา: `http://localhost:3000/api/auth/callback/line`
   - ตอนใช้จริง: `https://<โดเมนของคุณ>/api/auth/callback/line`
3. คัดลอก **Channel ID** ไปใส่ `AUTH_LINE_ID` และ **Channel secret** ไปใส่ `AUTH_LINE_SECRET`
4. เปลี่ยนสถานะ channel เป็น **Published** เพื่อให้คนอื่นล็อกอินได้ (ตอนเป็น Developing ล็อกอินได้เฉพาะบัญชีผู้พัฒนา)
5. (ไม่บังคับ) ใส่ LINE user id ของหัวก๊วนใน `ADMIN_LINE_IDS` ถ้าไม่ใส่ คนแรกที่ล็อกอินจะเป็นหัวก๊วน

## ขึ้นเว็บจริง (Vercel + Neon/Supabase)

1. สร้างฐานข้อมูล PostgreSQL ฟรีที่ [Neon](https://neon.tech) หรือ [Supabase](https://supabase.com) แล้วคัดลอก connection string
2. push โค้ดขึ้น GitHub แล้ว Import โปรเจกต์ใน [Vercel](https://vercel.com)
3. ตั้ง Environment Variables ใน Vercel:
   - ตั้งค่า: `DATABASE_URL`, `AUTH_SECRET`, `AUTH_URL` (= URL ของเว็บ), `AUTH_LINE_ID`, `AUTH_LINE_SECRET`
   - **ห้าม**ตั้ง `ALLOW_DEV_LOGIN`
4. ตั้ง Build Command เป็น `prisma migrate deploy && npm run build` เพื่อให้ตารางในฐานข้อมูลถูกสร้างหรืออัปเดตทุกครั้งที่ deploy
5. ใส่ Callback URL ของโดเมนจริงใน LINE Developers (ข้อ 2 ของหัวข้อด้านบน)
6. เปิดเว็บ ล็อกอินเป็นคนแรก (จะได้เป็นหัวก๊วน) → เมนู **ตั้งค่า** → ใส่ชื่อก๊วนและพร้อมเพย์

ใช้กับ Railway, Render หรือเซิร์ฟเวอร์ของตัวเองได้เหมือนกัน รัน `npm run build` แล้ว `npm start` ทำงานบน Node.js ปกติ

## การใช้งานในแต่ละรอบ

1. **หัวก๊วน** เปิดรอบใหม่ แล้วส่งลิงก์รอบในกลุ่ม LINE
2. **สมาชิก** กดลงชื่อ หัวก๊วนเพิ่มคนที่ไม่มีบัญชีให้ได้
3. ถึงสนาม หัวก๊วนกด **เริ่มตี** ระบบจัดคู่ลงทุกคอร์ท
4. จบแต่ละเกม หัวก๊วนกด **จบเกม** เลือกทีมที่ชนะและจำนวนลูก ระบบจัดเกมใหม่ลงคอร์ทนั้นทันที
5. ใครเหนื่อยกด **ขอพัก** เองได้ ถ้ากำลังเล่นอยู่จะได้พักหลังจบเกม
6. เลิกตี หัวก๊วนกด **จบรอบ & ออกบิล**
7. สมาชิกเปิดบิล สแกน QR จ่าย แล้วกด **แจ้งโอน** หัวก๊วนเห็นรายการที่หน้าแรกแล้วกด **ยืนยันรับเงิน**
