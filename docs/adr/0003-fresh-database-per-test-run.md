# 0003 · เทสต์สร้างฐานข้อมูลใหม่ทุกครั้ง แทนการล้างฐานข้อมูลเดิม

- สถานะ: ตัดสินแล้ว

## บริบท
เทสต์ integration กับ E2E ต้องเริ่มจากฐานข้อมูลว่าง วิธีที่พบบ่อยคือ `prisma migrate reset` ซึ่งลบข้อมูลทั้งหมด ถ้าตั้ง URL ผิดไปชี้ฐานข้อมูลจริง ข้อมูลเงินของก๊วนจะหาย (Prisma ก็บล็อกคำสั่งนี้เมื่อรันโดย AI agent ด้วย)

## ตัดสินใจ
แต่ละครั้งที่รันเทสต์ จะสร้างฐานข้อมูลใหม่ชื่อ `<ชื่อฐาน>_<run id>` บนเซิร์ฟเวอร์เดียวกัน แล้วรัน `prisma migrate deploy` (ไม่ลบอะไร) และชื่อฐานข้อมูลตั้งต้นต้องมีคำว่า `test` หรือ `e2e` ไม่อย่างนั้นเทสต์จะไม่ยอมรัน

## ผลที่ตามมา
- ไม่มีทางลบข้อมูลจริงจากการรันเทสต์
- ในเครื่องนักพัฒนา ฐานข้อมูลเทสต์เก่าจะสะสม ให้ลบเองเป็นครั้งคราว
  - ใน CI ไม่มีปัญหา เพราะ Postgres ถูกสร้างใหม่ทุกครั้ง
