# 0002 · ออกแบบสำหรับมือถือก่อน

- สถานะ: ตัดสินแล้ว (31 ต.ค. 2569 โดยเจ้าของระบบ)

## บริบท
ระบบถูกใช้ที่สนาม หัวก๊วนถือโทรศัพท์มือเดียว อีกมือถือไม้แบด สมาชิกเปิดดูคิวหรือจ่ายเงินจากโทรศัพท์

## ตัดสินใจ
- ออกแบบที่ความกว้าง **360–390px** ก่อน จอใหญ่เป็นส่วนเสริม
- เมนูหลักเป็นแถบด้านล่างไม่เกิน 5 รายการ เมนูที่ใช้ไม่บ่อย (ตั้งค่า) อยู่ในหน้า "ของฉัน" และ sidebar บนจอใหญ่
- ฟอร์มย่อยเปิดเป็น bottom sheet (`ui/dialog.tsx`) ไม่เปลี่ยนหน้า
- ตาราง: คอลัมน์ที่ไม่จำเป็นซ่อนบนมือถือ (`hide="sm"`) แล้วย้ายข้อมูลนั้นไปเป็นบรรทัดเล็กใต้ชื่อ
- งานที่ทำบ่อยในสนาม (จบเกม ขอพัก จ่ายเงิน) ต้องทำได้ใน 2 แตะ
- ปุ่มสูงอย่างน้อย 40px

## ผลที่ตามมา
- E2E รันบนโปรไฟล์ Pixel 7 เป็นหลัก
- หน้าจอใหญ่ใช้งานได้แต่ไม่ใช่เป้าหมายหลัก ยกเว้นโหมดจอที่สนาม (เฟส 4)
